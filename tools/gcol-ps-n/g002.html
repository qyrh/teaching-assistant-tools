玩法说明

1. 先选难度（初级 / 中级 / 高级），每一局的关卡顺序、题目数据和配色都会随机变化，多玩几局也不重样。
2. 每一关都要动手操作：拖动尺子对齐刻度、把卡片拖进单位筐、拖括号量相差的长度、装盒子、倒雨花石、举竹竿……操作对了才能过关。
3. 顶栏实时显示用时和步数，游戏区上方显示第几关和星星进度。
4. 遇到困难可以点「揭示答案」看思路；「重新开始」会换一批新题目重来；「返回难度选择」回到主界面。
5. 记住小锦囊：1米 = 100厘米；量长度时，把尺子的 0 刻度对准物体的一端，看另一端对着几；用断尺量，要用「终点刻度 − 起点刻度」。
