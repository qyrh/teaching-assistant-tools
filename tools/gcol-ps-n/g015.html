规则说明
1. 玩法：每局 4 个探险任务。点选卡片再点空格放进去（或直接拖动），全部放好后点【检查】。
2. 任务类型：数位表拼图 / 读零侦探篮 / 小数排队 / 小数点搬家（大数改写）/ 规律接龙 / 运算律变身卡 / 行程时间滑块。
3. 锦囊：每级末尾的 0 不读，级前级中的 0 都要读；改写就在万位或亿位右下角点小数点；运算律先找"凑整"和"相同乘数"。
4. 小助手：【揭示答案】自动演示（该题不算独立完成）；【重新开始】换任务与配色。
