探险规则说明

1. 目标：每一关都有一幅几何图。图里藏着若干条线段 / 角 / 三角形 / 长方形（或车票、比赛），请你把它们全部点亮！
2. 操作：先点一个点，再点另一个点（也可以按住一个点直接拖到另一个点上），它们组成的图形就会被点亮；数长方形时，从一个格点拖到另一个格点框出长方形；数车票时注意箭头方向，往返两个方向算两种不同的船票哦。
3. 不重复：点到已经点亮过的图形，会得到提醒。数图形最重要的就是有序枚举——不重复、不遗漏！
4. 分组检查：右侧的分组表就是"有序数数"的好帮手：每一行数完打勾，全部数完就通关！
5. 按钮：「揭示答案」可观看完整枚举过程和算式；「重新开始」换一道同类型的新题再来一次；「返回难度选择」随时回到首页。
6. 小惊喜：每一关都会随机更换一种主题色；通关有彩纸庆祝，右上角还能看到用时和操作次数统计。争取用最少的操作、最短的时间拿满三颗星！
