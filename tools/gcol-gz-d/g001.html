玩法说明 · 零点探险队

宝藏是什么？

使 f(x)=0 的实数 x 叫函数的零点，它既是方程的实根，也是图象与 x 轴交点的横坐标。 若 f(x)=h(x)−g(x)，那么 f 的零点个数 = y=h(x) 与 y=g(x) 两图象的交点个数——这就是数形结合的钥匙。

四种探险玩法

  • 探测线：上下拖动（或旋转）彩色探测线，观察它与曲线的发光交点，交点数达标后按"就是它，锁定！"
  • 零点定位夹：拖动 a、b 两个夹子，当 f(a) 与 f(b) 异号（一正一负）且曲线连续不断时，区间内必有零点，按"锁定零点区间"收下它；全部找齐后交卷。
  • 寻宝旗：直接在曲线与 x 轴交点附近的 x 轴上点击插旗，找齐所有零点后交卷。
  • 参数区间：先拖探测线（或数轴上的菱形探针）探索交点数如何随参数变化，再拖数轴上"左/右"两个手柄涂亮答案区间，提交范围。

贴心提示

  • 拖到特殊位置（如相切处）附近会自动"吸附"，帮你稳稳停住。
  • 右上角实时显示时间与步数；每关不揭示而独立通关可得一颗星。
  • 卡住了可以按"揭示答案"看方法锦囊（该关不计星），随时可按"玩法说明"回来看规则。
逢考必记（本模型方法库）
1. 零点 ⇔ 方程的实根 ⇔ 图象与 x 轴交点；
2. 零点存在定理：图象在闭区间上连续不断，且 f(a)·f(b)<0，则区间内有零点；再配合单调性可确定零点个数；
3. 图象法：f(x)=0 ⇔ h(x)=g(x)，数两图象交点；
4. 参数问题三大思路：直接法、参数分离法、数形结合法。
