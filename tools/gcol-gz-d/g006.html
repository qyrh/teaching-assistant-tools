探险手册 · 规则说明

任务目标：你是计数探险队的调度师。每关有一道真题，你要从零件库里取出"每一步 / 每一类的方法数"，按正确的计数结构摆上装配带，再用连接器把它们连起来。结构正确，水晶就会沿路线点亮终点灯塔！
分类加法计数原理（＋加法岔路）：完成一件事有 n 类办法，第 k 类有 mk 种方法，任选一类即可完成（类类独立、不重不漏），则 N = m1+m2+…+mn。路线图上表现为并行的岔路。
分步乘法计数原理（×乘法索桥）：完成一件事需 n 个步骤，第 k 步有 mk 种方法，每步依次完成才算完成（步步相依、缺一不可），则 N = m1×m2×…×mn。路线图上表现为首尾相接的索桥。
类中有步：m1m2m3 + m4m5（类间相加、类内相乘）；步中有类：m1(m2+m3+m4)m5。
间接法（－排除闸）：正难则反！先算出全部方法数，再减去不合要求的方法数。路线图上不合要求的路线会被请出队伍。
操作方法：① 点选或拖动零件卡到装配带（可反复取用）；② 拖动连接器放到两个零件之间，或直接点按连接符在 ＋ / × / － 之间切换；③ 点零件右上角的 ✕ 可移除；④ 装好后按"启动护送！"检验。部分关卡有探秘小装置（钢琴键盘 / 涂色板 / 字母方格），大胆去点！
三档难度：初级=例题级，中级=练习级，高级=变式综合级。每局随机抽 3 关，全部点亮即任务达成！
