规则说明 · 波形工坊

一、四个魔法把手（都在你手中的彩色实线上）

  • “峰”把手（峰点上）：上下拖动改变振幅 A；左右拖动改变周期，也就是 ω。
  • “中”把手（下降段与中线的交点）：上下拖动改变上下平移量 B。
  • “一”把手（“第一点”：上升段与中线的交点）：左右拖动改变 φ，相当于左右平移图象。
  • “五”把手（“第五点”：第一点向右平移一个周期处）：左右拖动改变周期 T，ω = 2π/T。

拖动时把手会自动吸附到横向 π/12、纵向 0.5 的格子线上。当你的实线与金色虚线目标曲线完全重合（指令关为四项参数全部正确）时，本关即完成！

二、数学锦囊（解题模型 20）

  • 振幅与中线：最高点 M、最低点 m，则 A = (M−m)/2，B = (M+m)/2。
  • 周期：相邻两个峰点（或谷点）的间距就是一个周期 T，且 ω = 2π/T。
  • 五点法：第一点满足 ωx₀ + φ = 0，所以 φ = −ωx₀。
  • 图象变换两种途径：先平移后伸缩，平移 |φ| 个单位；先伸缩后平移，平移 φ/ω 个单位——平移都是针对 x 而言的。
  • 平移前后函数名不一致时，先用诱导公式化为同名函数，例如 cos θ = sin(θ + π/2)。
