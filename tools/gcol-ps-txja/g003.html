第 1 / 3 题 题目来源 本题星星：—

放大槽（橙色高墙）

把每一项换成更大的数 → 和变大 → 高墙

缩小槽（蓝色矮墙）

把每一项换成更小的数 → 和变小 → 矮墙

放缩砖托盘（拖进上面的槽，或先点砖再点槽）

先把一块砖拖进「放大槽」试试！

游戏规则 · 放缩法寻宝

目标：每道题都是一串分数的和（或与它有关的算式），不用硬算出精确值，只要夹出它的整数部分。

第1步·立高墙（放大）：从托盘挑一块砖，拖进「放大槽」。这块砖的含义是"把每一项都换成某个更大的数"，于是总和被放大，高墙就立起来了。

第2步·立矮墙（缩小）：再挑一块砖拖进「缩小槽」，"把每一项都换成某个更小的数"，总和被缩小，矮墙立起来。

矮墙 < 原式 < 高墙 —— 原式被夹在两墙之间！

第3步·点宝石：两墙之间若只夹住一颗整数宝石（发亮的那颗），点击它就通关！若夹住好几颗，说明缝隙太宽，换更贴身的砖重新夹。

小心陷阱砖：有的砖写着"每一项都换成 1/7"，可是原式里明明有比 1/7 大的数、也有比 1/7 小的数——这种砖放进哪个槽都会被弹回来，并告诉你原因。

计分：步数越少星越多（本题 3 步内完成 = 3 颗星）。右上角有计时和步数。
