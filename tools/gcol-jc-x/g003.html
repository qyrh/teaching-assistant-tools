a > 0 开口向上，a < 0 开口向下；|a| 越大开口越窄。滑块每格 0.25。

玩法说明

目标：调整抛物线 y = a(x − h)² + k，让它同时穿过所有幸运星并点亮全部条件徽章。判定是实时的——操作到位的那一瞬间，星星和徽章就会亮起！

拖动抛物线：用手指或鼠标按住抛物线（或顶点圆点）拖动，抛物线随之平移，顶点会自动吸附到半个格点。水平方向改变 h（对称轴），竖直方向改变 k（顶点高度）。

调节开口：拖动右侧滑块改变 a。a 为正开口向上，为负开口向下；|a| 越大开口越窄。部分关卡会锁定 a 或对称轴，考验平移的功力。

读图：金色虚线是目标直线（对称轴或直线）；画布顶部实时显示当前解析式；与 x 轴的交点会用小圆点标出，涉及弦长与直角的关卡还会画出 A、B、P 的连线。

小贴士：右上角记录用时与步数。遇到困难可以点「揭示答案」看思路并观看演示动画。三档难度由浅入深，祝你在星空旅程中收获满满！
