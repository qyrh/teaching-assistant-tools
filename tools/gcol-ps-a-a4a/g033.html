玩法说明

欢迎来到彩虹环道大挑战！这里有两条黄金法则，是全部关卡的钥匙：

法则一（背向而行 = 相遇问题）：两人每相遇一次，合走一整圈；相遇 n 次就合走 n 圈。时间 = 路程和 ÷ 速度和。
法则二（同向而行 = 追及问题）：快者每追上慢者一次，就多走一整圈；追上 n 次就多走 n 圈。时间 = 路程差 ÷ 速度差。

你将要做的操作：

  1. 拖动时间滑块：两位小朋友会按各自的速度沿跑道实时奔跑，在正确的相遇/追上时刻松手定格；
  2. 拖动小人摆位：异地出发时，把出发点摆到题目要求的弧长距离；
  3. 拖动速度滑块：当一回速度调度员，让相遇/追上时刻恰好命中目标；
  4. 拖人回起点：第 n 次相遇后，看看还差多少米回到出发点。

每完成一个小任务都可以「揭示答案」看完整解析；「重新开始」可以重摆本关；右上角有用时和操作步数统计。通关后有惊喜庆祝，加油！
