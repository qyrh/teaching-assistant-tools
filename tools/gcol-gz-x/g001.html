你是测绘探险队的领队。每局共 3 关，每关一种测绘装置，全部通关即寻宝成功！右上角实时显示计时与步数，步数越少，星星越多。

余弦定理：三角形任何一边的平方，等于其他两边平方的和，减去这两边与它们夹角的余弦的积的两倍：
a² = b² + c² − 2bc·cosA
推论（已知三边求角）：cosA = (b² + c² − a²) / (2bc)
勾股特例：夹角为 90° 时 cosA = 0，余弦定理变成勾股定理；
判形方法：最大边² ＜ 其余两边平方和 → 锐角；相等 → 直角；大于 → 钝角。大边对大角。
  • 平方天平：把 b²、c² 原料块拖上右盘；判断 cosA 的正负，把「余弦修正块 2bc·cosA」放到正确的盘子（值为 0 时送回收站），天平平衡即开启金蛋，得到第三边 a。
  • 角度罗盘：拖动亮色手柄改变夹角∠C，对边 AB 随之伸缩，让它精确等于目标长度即可锁定（先用推论算出 cosC 会又快又准）。
  • 形状分拣码头：把三角形卡片拖进「锐角 / 直角 / 钝角」三个码头，依据是比较最大边的平方与其余两边的平方和。
  • 实景测绘图：通读测绘任务（条件都在文字和图中），算出答案后把旗帜拖到数轴上的正确位置。
  • 范围探测器：拖动两个空心手柄，框出满足条件的开区间范围。
