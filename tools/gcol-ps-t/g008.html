玩法说明

什么是分类枚举？
要数清一堆东西的总数或种数时，先选一个恰当的分类标准，把所有情况分成互不重复的几类，再一类一类按顺序列举，做到不重复、不遗漏，最后把每类的个数加起来。

怎么玩？

1. 选择难度（初级 / 中级 / 高级），每局随机抽取 3 个收集任务。
2. 每个任务都要动手操作：拖卡片、贴邮票、描正方形、连线、摆领奖台……每操作出一种新情况，它就会自动收进右侧「收集图鉴」的相应类别里。
3. 把图鉴集满（收集数 = 总数）就过关！重复的情况收不进去，想想还漏了哪一类。
4. 右上角显示时间和步数；实在想不出来可以点「揭示答案」看完整列举过程。

两个小口诀（分类枚举的关键）
· 分类要全——分完类要把每一类里的每种情况都列出来，才不会遗漏；
· 分类要清——类与类不能互相包含，才不会重复；情况多时可以先排除一部分，缩小范围再列举。
