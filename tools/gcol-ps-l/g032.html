玩法说明 · 小数锦囊

欢迎来到「小数点亮之旅」！每一关都要动手操作才能点亮小数，一起来吧！

玩法一：彩带 / 方格涂色坊

把整个图形看作"1"。按住拖动涂色：一位小数→涂满几条彩带（十分之几）；两位小数→涂满几个小格（百分之几）。涂的份数正好等于目标小数就过关，涂法不唯一。

玩法二：神奇米尺

拖动大圆点指针（点一下米尺也行），让它停在题目给的分米 / 厘米 / 毫米刻度上，松手确认。米尺会实时告诉你：它等于几分之几米、写成小数是多少米。

玩法三：数位搭建屋

把"百、十、一、十分之一、百分之一、千分之一、万分之一"这些计数单位筹码拖到对应的数位下面，搭出题目组成的小数。点一下数位里的筹码可以放回一个。

玩法四：卡片组数台

把数字卡片拖进格子，把小数点卡片拖到两个数字之间的金色位置，摆出符合全部要求的数。摆法不唯一，点一下放好的卡片可以放回卡片堆。

小数锦囊（读写方法）

1. 分母是 10、100、1000……的分数都可以用小数表示：一位小数表示十分之几，两位小数表示百分之几，三位小数表示千分之几。

2. 读小数：整数部分按整数的读法读，小数点读作"点"，小数部分要依次读出每个数字；整数部分末尾的 0 都不读，小数部分的 0 都要读出来。

3. 写小数：整数部分按整数的写法写，小数点写在个位右下角，小数部分依次写出每个数字。

4. 小数中每相邻两个计数单位间的进率都是 10。
