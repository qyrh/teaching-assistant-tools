小贴士：天平平衡就是等式！等式性质一：两边同时加（或减）同一个数，仍相等；等式性质二：两边同时乘（或除以）同一个不为 0 的数，仍相等。每局题目与配色都会随机变化，多玩几局不重样。

游戏规则

  1. 选择难度后进入挑战，每局共 3 关，每关一道实际问题。
  2. 第1步 搭建方程：把 x 货箱、倍数夹（×k）、砝码（加）、气球（减）拖到天平两边的盘上，摆出题目的等量关系，然后点「检验方程」。点盘上的零件可以取回重来。
  3. 第2步 解方程：把操作片拖到天平中央的「两边同时」圆台。加砝码、放气球、用等分器，让左边只剩一个 x 货箱，货箱打开就通关！注意：把操作片拖到单独一个盘上，天平会歪掉——等式两边必须同时做相同的变化。
  4. 右上角显示用时、步数和关卡。失误越少、越少看答案，星星越多！
等式的性质（解方程的法宝）：两边同时加（或减）同一个数，天平仍平衡；两边同时乘（或除以）同一个不为 0 的数，天平仍平衡。解 ax±b=c 时，先把 ax 看成一个整体，请走零散砝码，再两边同时等分。
