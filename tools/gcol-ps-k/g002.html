玩法说明

怎么点亮竖式？

  1. 看算式，列好竖式，从个位开始，一位一位往上算。
  2. 这一位不够减时，上方会有一个闪光的【借1】按钮，点亮它——借一当十！如果紧挨的数位是 0 借不到，就沿着闪光按钮一路向上借。
  3. 算出这一位的差后，点击（或拖动）下方数字卡，把数字填进发亮的格子里。
  4. 先减第一个减数求出差，再把第二个减数写在差的下面接着减。两步都完成，这道题就点亮啦！

秘籍口诀（课本秘籍5）

  • 数位对齐，从个位算起。
  • 不够减，向高位借一当十。
  • 连续减法分两步：被减数先减第一减数；在差的下方对齐数位写上第二减数，再求出结果。

小提示：差的最高位是 0 时，写最后得数可以省略这个 0 哦。
