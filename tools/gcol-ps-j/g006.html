规则说明

  1. 先在菜单选择难度（初级 / 中级 / 高级），每一关都会给你一块完整的实心方体。
  2. 看任务卡上的目标表面积和隧道（或梁）数量要求。
  3. 在左边的俯视图 / 正视图 / 侧视图上点击格子：隧道关卡会沿该方向开凿一条贯通的 1×1 隧道；梁关卡会放置一整根梁（再点别处会替换上一根）。
  4. 每凿一下，右边的立体模型和三个"方向可见小面"计数都会实时变化——这就是三视图标数法：表面积 = 上下方向 ＋ 前后方向 ＋ 左右方向。
  5. 当当前表面积 = 目标表面积，且隧道（梁）数量恰好符合要求，本关自动过关，星星到手！
  6. 工具按钮：撤销一步收回上一次开凿；重新开始还原本关方体；揭示答案演示一种可行凿法（本关星星会减少）；题目原文查看教材原题；秘籍图鉴查看方法总结。
  7. 立体模型可以用手指或鼠标拖动旋转，钻进洞里看看内壁！

秘籍口诀

顶点与棱、面上挖，注意增加和减少的面；挖洞要和原来比，多了少了要弄清；表面积三视不能少，配合标数快又好！

三视图标数法

把立体图形从上、前、左三个方向分别观察：每个方向能看到的（含洞口内壁折算的）小面数，三个方向相加就是表面积。本工坊里三个视图下方的计数就是它！
