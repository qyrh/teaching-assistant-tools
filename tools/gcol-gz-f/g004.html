舱段一 · 向量判定桥

把每对方向向量卡片拖拽到正确的桥墩上：

  • ∥ 平行：a = k·b（对应坐标成比例）；
  • ⊥ 垂直：a·b = 0（数量积为零）；
  • 相交 · 一般：既不平行也不垂直。

舱段二 · 法向量调谐台

平面 α 内给出两个不共线向量 u、v。拖动三个旋钮调节 n=(x, y, z)，让两个仪表 n·u 与 n·v 同时归零——这时 n 就是平面的法向量（任何非零倍数都算对，n 不能取零向量）。

舱段三 · 空间角对接舱

根据读数与公式先算出角 θ，再拖动表盘指针：松手时误差在 ±2° 内即点亮。

  • 线线角：cosθ = |a·b| / (|a||b|)
  • 线面角：sinθ = |a·n| / (|a||n|)
  • 二面角（夹角）：cosθ = |n₁·n₂| / (|n₁||n₂|)

舱段四 · 距离光束

点到平面的距离 d = |AP·n| / |n|。算出 d 后拖动光束游标，误差 0.04 内点亮。
