🔆 玩法：把 (a+b)n 看成 n 个因子盒。每个盒子可以点亮（选 b）或熄灭（选 a）——点亮 k 个盒子，就得到展开式的第 k+1 项！点一点盒子，观察指数探照屏上 x 的指数如何变化。当指数正好照到当前任务要的数时，按【锁定此项】收进收集架；若任务提示"可能不存在"，就把 k=0…n 全部探照一遍，再按【报告：没有这一项】。高级难度的"有理项收集"：指数为整数时把当前项卡拖进收集架。

📜 星河工坊 · 规则说明

🏯 星站一 · 杨辉宝塔

杨辉三角记录着 (a+b)n 的二项式系数 Cnk。塔的每一行两端都是 1，中间每个数都等于它肩上两数之和（Cnk = Cn-1k-1 + Cn-1k）。把数字石砖拖进空位补全宝塔；高级难度还有"整行求和"挑战（第 n 行所有数之和 = 2n）。

🔦 星站二 · 通项探照灯

展开式的第 k+1 项来自"从 n 个因子里选 k 个取 b"：Tk+1 = Cnk an-kbk。点亮 k 个因子盒就是在选 b！探照屏实时显示化简后的指数与系数，照到任务要求的指数就【锁定此项】。注意：有些项在展开式中根本不存在（指数方程无整数解），要扫遍全部 k 再报告"没有这一项"。高级难度会出现"收集全部有理项"：只有当指数是整数时，当前项卡才能拖进收集架。

🎚 星站三 · 赋值点将台

设 f(x) = 展开式。令 x=1 → 各项系数之和；令 x=0 → 常数项；令 x=-1 → 正负交替和。偶次幂系数和 = (f(1)+f(-1))/2，奇次幂系数和 = (f(1)-f(-1))/2。二项式系数之和与字母无关，等于 2n（用灯串点亮 n 盏灯获得）。
