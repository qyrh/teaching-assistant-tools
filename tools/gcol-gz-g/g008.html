📋 玩法与知识锦囊

玩法

  • 散点分拣站：把散点图卡片拖到正确的分拣架上（正相关 / 负相关 / 几乎不相关，高级难度还有「曲线相关」）。
  • 相关系数排座站：观察每幅散点图云朵的方向与松紧，把 r 数值胸章拖到对应的图下。
  • 回归线搭建工坊：在画布上拖动两个金色圆柄调整直线，让所有残差（竖直小方块）的总面积尽量小；达标后再沿横轴拖动预测探针到指定 x 处读出预测值。
  • 独立性检验信号站（高级）：把四个数字磁贴拖进 2×2 列联表（要让行合计、列合计都对得上），观察 χ² 信号灯，最后把结论徽章拖到结论台。

知识锦囊（本章要点）

  • 正相关 / 负相关：散点从左下向右上发展 → 正相关；从左上向右下发展 → 负相关。
  • 相关系数 r：-1 ≤ r ≤ 1；r>0 正相关，r<0 负相关；|r| 越接近 1 线性相关越强，越接近 0 越弱；|r|>0.5 认为线性相关显著，|r|<0.3 几乎无线性相关。r 只度量线性相关，呈规则弯曲的散点不能只用 r 判断。
  • 最小二乘法：使残差平方和 Σ(yᵢ-ŷᵢ)² 最小。斜率 b̂ = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²，截距 â = ȳ - b̂x̄；回归直线必过样本中心 (x̄, ȳ)。
  • 独立性检验：χ² = n(ad-bc)² / [(a+b)(c+d)(a+c)(b+d)]。χ² ≥ 3.841 → 有 95% 把握认为两分类变量有关联；χ² ≥ 6.635 → 有 99% 把握。
