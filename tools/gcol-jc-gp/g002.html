📖 玩法说明（分式方程修复手册）

知识锦囊：分母中含有未知数的方程叫分式方程。解法三步曲——

  • 去：方程两边同乘最简公分母，化成整式方程；
  • 解：解这个整式方程；
  • 验：把整式方程的根代入最简公分母——不为 0 才是原方程的解；为 0 就是增根，原方程无解。

操作方法（全程拖拽）：

  • 第1步 去分母：把正确的「最简公分母钥匙」拖到方程下方的锁孔上，分数线就会消散；
  • 第2步 天平移项：把卡片拖到天平另一盘，卡片过河自动变号！让 x 卡集中在一盘、数卡集中在另一盘，再把「÷系数」砝码拖上天平支点，即可读出根；
  • 第3步 检验闸门：把求出的根拖进「代入探测仪」，观察各分母的值——公分母不为 0 走「有效解之门」，为 0 就要把根送进「无解之门（增根）」；
  • 增根侦探（高级）：先把候选根拖进探测器找出使分母为 0 的增根，再把增根代入整式方程求参数；无解还有另一条路——整式方程本身矛盾；
  • 列方程装配：先把数量卡片拖进带说明的方程槽位，装对才能继续。
