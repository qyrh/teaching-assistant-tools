半角旋转工坊

顶点相同的两个角，一个是另一个的一半（45°与90°、60°与120°），就是半角模型。
遇到半角怎么办？——旋转拼一拼，两条短线变一条长线！

初级 · 彩虹之门（调出半角） 亲手拖动点 M、N，把 ∠MAN 调成 45°、把 ∠MDN 调成 60°，再用周长拼条验证“MN = BM + DN”的魔法结论。
中级 · 星辰之门（旋转拼板） 抓住角板手柄，把三角形绕顶点旋转 90°／120°，亲手完成“旋转 + 两次全等”的证明拼板。
高级 · 荣耀之门（模型寻宝） 用半角模型解决课本原题变式：周长不变之谜、对角线上的 MN、斜边上的 45°，拼出答案！

规则说明

什么是半角？

两个角顶点相同，且一个是另一个的一半：45° 是 90° 的半角（正方形、直角中常见），60° 是 120° 的半角（等边三角形 + 120°等腰三角形中常见）。

两大魔法结论

  • 正方形 ABCD 中，若 ∠MAN = 45°，则 MN = BM + DN，且 △MCN 的周长 = 边长 × 2。
  • 等边 △ABC（边长 a）与 ∠BDC=120° 的等腰 △BDC 中，若 ∠MDN = 60°，则 MN = BM + CN，且 △AMN 的周长 = 2a。
  • 证明绝招：旋转 + 两次全等——把含 BM 的三角形绕顶点旋转，让 BM 与 DN 接成一条线。

怎么玩

  • 拖动亮点：按住带光圈的点（如 M、N、E），沿图形边滑动，实时读数会跟着变。
  • 旋转拼板：抓住半透明角板上的大圆手柄，绕中心转起来，转到虚线目标处松手即可吸附。
  • 拼条入槽：把长度条拖进凹槽或卡槽；凹槽恰好铺满（或斜条与 MN 恰好一样长）就过关。
  • 接近目标时会发亮提示，松手即可自动吸附。
