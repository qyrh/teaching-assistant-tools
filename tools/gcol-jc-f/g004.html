玩法说明 · 奔驰模型

它是谁？等边三角形 ABC 内有一点 P，把 PA、PB、PC 三条线段连出来，图形很像小汽车的三叉星徽，所以这个题型叫做奔驰模型。
核心方法（名师点拨）求角度与面积都靠"构造等边三角形 + 手拉手全等"：
  1. 把线段 AP 绕点 A 旋转 60° 得到 AP′（其实绕哪个顶点、往哪边转都可以，共有 6 种方法）；
  2. 于是 △APP′ 是等边三角形，PP′ = PA；
  3. 再由"手拉手"全等 △AP′B ≌ △APC，得 P′B = PC；
  4. 若 PA、PB、PC 满足勾股关系 PA² + PB² = PC²，则 △PBP′ 中出现直角，∠APB = 60° + 90° = 150°。
操作方式
  1. 定心：按住画布中的彩色光点 P 拖动，右侧仪表盘实时显示三个距离，三个全部变绿即达标（点"提示"可借出魔法圆规弧线）；
  2. 旋转：按住画布拖动，把发光光杆绕点 A 顺时针转到 60° 刻度，出现绿色光圈时松手即可锁定；
  3. 天平：把三块"平方数砝码"拖进左右托盘，让 PA² + PB² = PC²，天平放平即通关；
  4. 拼角：把角度拼块拖进两个空位，拼出 ∠APB 的度数。
右上角有计时器和步数；卡住了可以点"提示"或"揭示答案"。祝你在星徽工坊收集满满星章！
