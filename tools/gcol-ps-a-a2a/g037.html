排队的学问 · 队列图大闯关

画好队列图，“第几、有几、之间、从谁数到谁”一图看懂！
每局随机抽 3 关，主题色也会随机变化哦。

用时 00:00 步数 0
题目
🎉 恭喜通关，队列小达人！

玩法说明

口诀要记牢（最重要！） “第几” → 数到自己，包括自己
“有几” → 不包括自己
“谁和谁之间” → 不包括两头的人
“从谁数到谁” → 包括两头的人
画队列图四步 1. 定方向：看清排头（前）在哪边
2. 放人物：把关键人物拖进队伍里
3. 标数量：想清楚每段“包括谁、不包括谁”
4. 找答案：看图找到问号对应的那一段
操作方式 · 直线队列：拖动小人、拖动排尾旗，把所有条件变绿
· 方阵关卡：点格子放人物，用“＋/－”调整队伍行数和列数；转向关要先点“全体向右转”
· 条件全绿后，把正确的数量卡拖进答案框
· 顶部有计时和步数；卡住了可以点“揭示答案”看解析
