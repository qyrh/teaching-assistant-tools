📖 游戏规则与玩法

  • 核心目标：根据题目，把树苗种到正确位置，让种树方案完全符合题意。
  • 种树（初/中级）：从下方"树苗库"里 拖动 一棵树苗，放到路面/花坛边的虚线"树坑"上。点一下已种的树可以把它拔起。
  • 调间隔（高级反向题）：左右 拖动滑块，观察棵数随间隔变化，找到正好排满的间隔。
  • 爬楼题：上下 拖动"爸爸"，把他放到正确楼层。
  • 实时统计：右下方显示"棵数 / 段数 / 总长"，帮你发现植树问题的公式。
  • 两个法宝：两端都种 → 棵数 = 段数 + 1；封闭图形（绕一圈）→ 棵数 = 段数。
  • 右上角有 计时 和 步数，挑战自己用更少步数通关吧！
  • 卡住了？点 揭示答案 可以看完整解析（建议先自己多探索）。
