📖 乘法彩虹探险 · 规则

🔥 初级：水晶熔炉（变加为乘）

  • 画面上有一排水晶，每个水晶上写着一个数。
  • 把相同数字的水晶全部拖进"熔炉"里。
  • 熔炉会自动把相同加数变成乘法：比如 4 个 3 变成 4×3=12。
  • 再加上熔炉外面剩下的数，就得到最终结果！
  • 点击"炼制"确认答案。

🌸 中级：因数花园（枚举法）

  • 题目给出一个"积"（比如 24）。
  • 把两朵数字花分别拖进 ( ) × ( ) 两个框里。
  • 如果两个数的积正好等于目标，这对算式就会点亮！
  • 从 1 开始按顺序找，不重复、不遗漏，找齐所有算式就过关。

⚖️ 高级：天平秘境（最大/最小填几）

  • 题目是一个乘法不等式，比如 ( )×9<35。
  • 拖动滑块改变括号里的数，天平和数字会实时变化。
  • 找到满足条件的最大（或最小）的数，点击"确认"。
  • 观察天平：左边<右边时，左盘在上；左边>右边时，左盘在下。
