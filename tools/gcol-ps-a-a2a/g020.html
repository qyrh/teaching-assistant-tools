本关任务

请在图上完成操作。

提示：先数一数每个点连出几条线（叫做"度数"）。度数是奇数的点叫"奇点"，是偶数的叫"偶点"。

📖 一笔画探险规则

一笔画，就是笔尖不离开纸、每条线只画一次，把整个图形完整地画出来。

🔑 核心秘密：看奇点

  • 奇点：连出线的条数（度数）是奇数的点（1、3、5…）。
  • 偶点：度数是偶数的点（2、4、6…）。
  • 图形只有 0 个或 2 个奇点时，才能一笔画成。
  • 0 个奇点：从任意点出发，能回到出发点（闭合路径）。
  • 2 个奇点：必须从其中一个奇点出发，到另一个奇点结束。

🛠 五种操作玩法

  • 找奇点：点一点，把你认为的奇点全部点亮。
  • 画路线：按顺序点击顶点，画出整条不重复的路线。
  • 去线法：点掉一条线，让奇点变成 0 或 2 个。
  • 添线法：连接两个顶点添一条线，让奇点变成 0 或 2 个。
  • 速达对决：把奖杯拖到能最先走完全程的探险者身上。

🎨 小贴士

把鼠标移到顶点上，会显示它的度数。每局颜色和题目都会变化，多玩几次也不会腻哦！
