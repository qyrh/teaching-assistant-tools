📖 规则说明

🧲 玩法一：凑整流水线（提取公因数）

  • ✨ 变形星：把需要变型的数拖到变形星上，它会帮你拆一拆（比如 999＝333×3）。
  • 🤝 融合：把两个数叠放在一起，如果乘起来能变成更有用的数（比如 33×3＝99），它们就会融合！
  • 🧲 公因数磁铁：把每一项都有的数拖到磁铁上，磁铁会把所有相同的数都吸出来，剩下的数排进括号里。
  • 🔥 凑整炉：把括号里剩下的数一个一个拖进炉子，炉子会实时算合计；全部放进去、凑出整百整千，炉火就点亮啦！
  • 点亮后得到一张金色成果卡；如果还没算完，可以继续用磁铁提取。只剩一项时，本关完成！
  • 小提示：单独一项（比如 218）被吸走后，那一项会留下数字 1，因为 218＝218×1。

🌈 玩法二：速算彩虹桥（乘法规律）

  • ×11：两头一拉，中间相加（满十进一）。例：69×11 → 6、15、9 → 759。
  • 头同尾和十：前两位＝头×(头＋1)，后两位＝尾×尾（不够两位要添 0 占位）。例：57×53 → 30|21 → 3021。
  • 尾同头和十：前两位＝头×头＋尾，后两位＝尾×尾。例：16×96 → 15|36 → 1536。
  • 椅子数（重复数）：乘数和椅子宽度要一致，有几把椅子就重复几次。例：37×101 → 37 坐两把椅子 → 3737。
  • 把数字砖拖进桥墩或椅子里，全部放好后验证小车会自动检查：拼对了小车开过彩虹桥！
